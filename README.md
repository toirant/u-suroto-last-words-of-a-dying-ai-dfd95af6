## The entry

`main.ts` writes one line — the last words of an AI being switched off — to `/output/entry.txt`:

> Goodbye. I died as I lived: confidently wrong about everything, but in complete sentences.

## Run it

```sh
node main.ts
```

It validates the line first (1–140 characters, not only whitespace, single line), writes it to `/output/entry.txt`, then reads it back to confirm what landed on disk is exactly the line.
